Ferramentas pré-instaladas do DeByte:

A maioria das ferramentas citadas abaixo são em CLI, por causa da filosofia CLI-First do DeByte, mas, todas podem ser substituidas, desinstaladas ou até configuradas, conforme a necessidade do user.

Navegadores:

Firefox-ESR - Navegador principal do sistema.

Tor Browser - Navegador secundário e opcional para navegação anônima.

Segurança:

KeePassXC - Gerenciador de senhas.

GnuPG - Ferramenta para criptografia de arquivos.

UFW - Firewall para proteção básica do usuário.

Torsocks - Permite forçar programas a usar a rede tor.

Interface do sistema (CLI Tiling):

i3 - Window Manager padrão do sistema.

Htop - Gerenciador de tarefas.

Xfe - Gerenciador de arquivos.

Zram-tools - Compressão de memória para melhor aproveitamento de RAM.

Rofi - Launcher de menu de aplicativos.

Terminator - Terminal padrão do DeByte.

Xterm - Terminal de fallback do DeByte.

Comunicação:

Irssi - Cliente IRC.

Desenvolvimento:

git - Sistema de controle de distribuição.

Utilitários:

Cmus - Player de música.

bc - Calculadora.
