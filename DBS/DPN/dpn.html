DeByte Protocol Network: Uma ferramenta de teste de rede

DPN é uma ferramenta de teste de rede, podendo testar, conectividade, DNS, HTTP e HTTPS e ainda sendo capaz de mostrar a interface do usuário na rede.

O que o DPN é capaz de fazer?:

DPN é capaz de:

Testar conexão;
Teste de DNS;
Teste HTTP;
Teste HTTPS + Versão TLS;
Mostrar interface do usuário;
Consultar vizinhos IPv4 e Ipv6 (Adicionado na Versão 3.0);

O DPN foi feito em bash, para ser leve, além de usar ferramentas do próprio sistema Linux.
