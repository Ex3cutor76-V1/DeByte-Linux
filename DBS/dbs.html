O que é o DeByte Shop?:

O DeByte Shop é um gerenciador de componentes do sistema DeByte, ele foi escrito puramente em Perl, é um dos scripts mais recentes que foi adicionado no DeByte na versão 3.0, o software usa o comando "dbs" que logo leva a um menu que irá te permitir escolher o que você quer fazer, se for instalar ferramentas da comunidade DeByte ou se você quer instalar componentes do DeByte ou até mesmo ver informações.

Objetivo principal do DeByte Shop:

O objetivo principal do DeByte Shop não é tentar substituir o "APT", na realidade o objetivo dele é fornecer uma forma mais fácil e automática de instalar componentes do sistema DeByte.
