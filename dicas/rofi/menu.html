Configurações do Rofi:

O rofi é o launcher de menu que permite com que você acesse os aplicativos com mais facilidade, pois é, simplesmente é com o Rofi que faz com que você evite usar comandos, ele também é uma das ferramentas essenciais do DeByte, uma vez que ele facilita o uso.

As duas configurações do rofi:

Configuração de execução:

# Tudo que estiver dentro deste bloco são configurações gerais do rofi
configuration {
    modi: "drun,run,window";
    show-icons: false;
    drun-display-format: "{name}";
    display-drun: "Apps";
    display-run: "Run";
    display-window: "Janelas";
}
@theme "debyte-theme"

Configuração de tema:
