Configuração de Layout de teclado:

A configuração de layout de teclado define como o sistema interpreta as teclas pressionadas pelo usuário. Essa configuração pode variar conforme a escolha feita durante a instalação do DeByte e pode ser alterada posteriormente conforme a necessidade do usuário. 

# Modelo físico do teclado
XKBMODEL=""
# Idioma das teclas
XKBLAYOUT=""
# Variação de Layout
XKBVARIANT=""
# Opção extra
XKBOPTIONS=""
# Controla comportamento da tecla Backspace
BACKSPACE=""
