Configurações do DeByte

No DeByte existe algumas coisas para facilitar na configuração do sistema, você pode alterar como você quiser, essas configurações são padrão do sistema e aqui será dito o que cada código de configuração de cada um serve ou como funciona.

  • Configuração i3
  • Configuração i3status
  • Configuração rofi
  • Configuração do terminator
  • Configuração do shell
  • Configuração do debyte-net
  • Configuração do xinitrc
  • Configuração do X11
  • Configuração do Zram
  • Configuração do layout de teclado
  • Configuração de fuso-horário
  • Configurações do Xterm

Caso queira fazer sua própria configuração use:

nano ~/.config/i3/config --> Configuração i3
sudo nano /etc/i3status.conf --> Configuração i3status
nano ~/.config/rofi/config.rasi --> Configuração rofi
nano ~/.config/rofi/debyte-theme.rasi --> Configuração do rofi
nano ~/.bashrc --> Configuração do Shell
sudo nano /usr/local/bin/debyte-net --> Configuração do debyte-net
nano ~/.xinitrc --> Configuração do Xinitrc
nano ~/.bash_profile --> Configuração do X11
sudo nano /etc/default/zramswap --> Configuração do Zram
sudo nano /etc/default/keyboard --> Configuração do layout de teclado
sudo nano /etc/timezone --> Configuração de fuso-horário
nano ~/.config/terminator/config --> Configuração do Terminator
nano ~/.Xresources --> Configuração do Xterm
