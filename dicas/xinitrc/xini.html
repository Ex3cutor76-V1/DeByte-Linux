Configuração do xinitrc:

O xinitrc é o ponto de entrada da sessão gráfica do usuário. Quando o X11 é iniciado pelo comando startx, ele procura o arquivo .xinitrc para saber quais programas devem ser executados, incluindo o window manager principal, que no caso do DeByte é o i3. 

# Apenas inicia o i3
exec i3 -c ~/.config/i3/config
