UFW: O firewall

O UFW (Uncomplicated Firewall) é uma ferramenta de gerenciamento de firewall no Linux. No DeByte, ele vem pré-instalado como uma opção de proteção básica para o usuário. Ele fornece uma interface simplificada para configurar regras de filtragem de rede, utilizando sistemas de firewall de baixo nível como o Netfilter, que inclui tecnologias como iptables e nftables.

O que é um firewall?:

O Firewall é um sistema que filtra o tráfego de rede com base em regras. Ele pode controlar conexões de entrada e saída, permitindo ou bloqueando determinados tipos de comunicação.

O que é uma regra no firewall?:

Uma regra é um tipo de instrução, por exemplo:

Se alguém tentar acessar a porta 80(HTTP), permita.

Se alguém tentar acessar a porta 23(Telnet), bloqueia.

O que significa "política padrão"?:

Além das regras, o firewall possui uma política padrão (default policy), que define o que fazer quando nenhuma regra corresponde ao tráfego.

Comandos do ufw:

estrutura: sudo ufw comando

comandos:

enable --> Ativar firewall.
disable --> Desativar firewall.
default ARG --> Define política padrão do firewall (exemplo: pemitir ou negar por padrão).
logging LEVEL --> Define nível de registro (Ou logs) do firewall.
allow ARGS --> Adiciona uma regra para permitir tráfego.
deny ARGS --> Adiciona uma regra para bloquear o tráfego.
rejects ARGS --> Adiciona uma regra para rejeitar tráfego.
limit ARGS --> Adiciona uma regra para limitar conexões.
delete RULE/NUM --> Remove regra específica ou uma regra pelo número.
insert NUM RULE--> Insere uma regra em uma posição específica da lista de regras.
prepend RULE --> Adicionar uma regra no início da lista de regras.
route RULE --> Adiciona regra de roteamento.
route delete RULE/NUM --> Remove uma regra de roteamento.
route insert NUM RULE --> Insere uma regra de roteamento em uma posição específica.
reload --> Recarrega regras do firewall sem desativá-lo.
reset --> Restaura o firewall para as configurações padrão. Removendo todas as regras.
status --> Mostra estado atual do firewall.
status numbered --> Mostra estado atual do firewall com regras numeradas.
status verbose --> Mostra informações detalhadas sobre o firewall.
show ARG --> Exibe um relatório ou informação específica do firewall.
version --> Mostra a versão do firewall.

Comandos de perfil de aplicações:

app list --> Lista perfis de aplicações disponíveis.
app info PROFILE --> Mostra informações sobre um perfil de aplicação específico.
app update PROFILE --> Atualiza perfil de aplicação.
app default ARG --> Define política padrão para perfis de aplicações.

Outras informações sobre as variáveis.

ARG é o valor que o comando espera receber (Exemplo: deny, allow, limit, etc.)

ARGS é um ou mais valores (Exemplo: 22, 2222, 443, 80, etc)

PROFILE é o nome do perfil de aplicação (Exemplo: OpenSSH, Yahoo, etc.)

RULE é uma regra completa do firewall (Exemplo: allow from IP/24 to any port 22.)

NUM é o número da regra (Exemplo: sudo ufw delete 3)
