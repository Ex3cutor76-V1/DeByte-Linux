Irssi: Cliente IRC

O Irssi é um cliente IRC em CLI que foi adicionado no DeByte para permitir que os usuários possam se comunicar. IRC (Ou também conhecido como Internet Relay Chat) é um protocolo de comunicação em tempo real criado em 1988 para conversas em grupo ou mensagens privadas.

Comandos do Irssi:

irssi --> Inicia o Irssi.
/connect sevidor --> Se conecta a um servidor.
/disconnect --> Desconecta do servidor atual.
/server --> Gerencia conexões com servidores.
/quit mensagem --> Fecha o Irssi enviando uma mensagem de saída.
/reconnect --> Reconecta o servidor.
/join #canal --> Entra em um canal.
/part #canal --> Sai de um canal.
/cycle --> Sai e entra novamente em um canal.
/list --> Lista canais disponíveis.
/names --> Lista os usuários do canal.
/nick nome --> Alterar apelido (nickname).
/whois nick --> Exibe informações sobre um usuário.
/who canal --> Lista usuários de um canal.
/query nick --> Inicia uma conversa privada.
/msg nick mensagem --> Envia uma mensagem privada
/me ação --> Envia uma ação.
/topic --> Exibe ou altera tópico do canal.
/invite nick #canal --> Convida usuário para um canal.
/kick nick --> Expulsa um usuário (Se permitido).
/ban nick --> Bane um usuário (Se permitido).
/mode --> Exibe ou altera modos do canal ou usuário.
/ignore --> Ignora mensagens de usuários.
/unignore --> Remove um usuário da lista de ignorados.
/away mensagem --> Define seus status como ausente.
/back --> Remove status de ausência.
/window --> Gerencia janelas do irssi.
/window list --> Lista janela abertas.
/window goto n --> Vai para uma janela específica (Troque "n" por um número da janela).
/help --> Exibe o ajuda do irssi.
/save --> Salva configuração atual.
/set --> Altera configuração.
/alias --> Cria um alias para comandos.
/script --> Gerencia scripts Perl carregados.
/exec --> Executa um comando do sistema operacional.
