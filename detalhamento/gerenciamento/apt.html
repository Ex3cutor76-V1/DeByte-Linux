APT: O gerenciador de pacotes padrão do sistema

No DeByte o gerenciador de pacotes principal é o APT ou também chamado por alguns de Advanced Package Tool, que é um gerenciador de pacotes, que é responsável por instalar, remover, atualizar e gerenciar programas, resolvendo assim automaticamente as dependências necessárias para o funcionamento de cada pacote.

Como o APT funciona?:

Os programas distribuidos para Debian normalmente são empacotados como .deb e o próprio APT trabalha em conjunto com o dpkg que é uma ferramenta de baixo nível responsável por instalar esses pacotes. No caso o fluxo seria este:

Comandos do apt:

sudo apt update --> Baixa a lista mais recente de pacotes disponíveis nos repositórios configurados.
sudo apt upgrade --> Atualiza todos os pacotes instalados para suas versões mais recentes.
sudo apt full-upgrade --> Permite instalar dependências novas e remover pacotes antigos, além de atualizar o sistema inteiro.
sudo apt install nome-do-pacote --> Instala um programa.
sudo apt remove nome-do-pacote --> Remove o programa, mas, deixa os arquivos de configuração.
sudo apt purge nome-do-programa --> Remove completamente.
sudo apt autoremove --> Limpa dependências não utilizadas.
sudo apt clean --> Limpa cache.
sudo apt autoclean --> Remove apenas os pacotes do cache que não podem mais ser baixados dos repositórios.
apt search nome-do-programa --> Procura programas.
apt show nome-do-programa --> Exibe informações.
apt list --installed --> Lista de pacotes instalados.

Mas também é possível instalar os pacotes .deb com o dpkg:

sudo dpkg -i programa.deb

Entretanto, o dpkg não resolve dependências automaticamente.

E caso queira desinstalar com o dpkg é só usar:

sudo dpkg -r nome-do-programa

Ou remover completamente:

sudo dpkg -P nome-do-programa

Ou

sudo dpkg --purge nome-do-programa

E caso você não saiba o nome do pacote você pode descobrir usando: 
dpkg-deb -f programa.deb Package
ou se caso ele estiver instalado use: 
dpkg -l

A configuração do APT no DeByte em: /etc/apt/sources.list

deb http://deb.debian.org/debian/ trixie main contrib non-free non-free-firmware
deb-src http://deb.debian.org/debian/ trixie main contrib non-free non-free-firmware

deb http://security.debian.org/debian-security trixie-security main contrib non-free
deb-src http://security.debian.org/debian-security trixie-security main contrib non-free

deb http://deb.debian.org/debian/ trixie-updates main contrib non-free non-free-firmware
deb-src http://deb.debian.org/debian/ trixie-updates main contrib non-free non-free-firmware
