Estrutura do sistema: A base Linux

O DeByte, por ser uma distribuição Linux baseada em Debian, segue o padrão tradicional da hierarquia de diretórios do Linux (Filesystem Hierarchy Standard - FHS). Essa organização define onde ficam arquivos do sistema, configurações, programas, dispositivos e dados dos usuários.

/:

A "/" é a raiz do sistema, no caso, ela é o ponto inicial de tudo.

/bin:

Nesta pasta contém os comandos do sistema como "ls", "chmod", "mkdir" entre outros.

/sbin:

Nesta pasta contém os comandos administrativos do sistem como o fdisk, reboot, mount, etc.

/boot:

São os arquivos necessários para iniciar o sistema.

/dev:

Contém os dispositivos tratados como arquivos, por exemplo: o sda sendo tratado como o HD ou SSD, sdb como o pen drive, etc.

/etc:

Contém as configurações do sistema, como por exemplo o /etc/i3status.conf do i3status, /etc/apt/sources.list do apt e entre outros.

/home:

É o diretório do usuário.

/root:

É o "home" só que do administrador.

/lib e /lib64:

São as bibliotécas essenciais usada pelos programas.

/media:

Contém a montagem automática de dispositivos removiveis.

/mnt:

Serve para a montagem manual (Exemplo: mount /dev/sdb1 /mnt)

/opt:

São programas opcionais instalados no sistema, um exemplo? O único instalado de forma opcional no DeByte é o tor browser que está localizado nessa pasta.

/proc:

São os sistemas de arquivos virtual criado pelo kernel, mostrando informações do sistema em tempo real, exemplo: para a CPU seria /proc/cpuinfo, para memória RAM é /proc/meminfo e para processos /proc/[PID].

/sys:

Expõe informações sobre o hardware e kernel.

/run:

Armazena os dados temporários usados durante a execução.

/tmp:

Arquivos temporários.

/usr:

Aqui contém os programas e recursos instalados.

/var:

Aqui contém os dados que mudam constantemente, no caso por aqui você pode encontrar as logs do sistema, por exemplo, para encontrar as logs é /var/log/, já o cache /var/cache/, enquanto o banco do dpkg é /var/lib/dpkg/.

/lost+found:

Nesta pasta contém arquivos recuperados pelo fsck

/srv:

São os dados fornecidos por serviços.

vmlinuz:

Este é o próprio Kernel Linux que durante o boot a sequencia é:

Grub --> vmlinuz --> Linux Kernel

initrd.img:

É o initramfs, ele é o que carrega os drivers e prepara o sistema antes de montar a raiz real.
