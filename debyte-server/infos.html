O que é o DeByte Server?:

O DeByte Server é uma versão derivada do DeByte Linux com um foco mais para servidores.

Lista de app's do DeByte Server:

ufw --> Firewall para segurança básica 
docker --> Contêiner
git --> Versionamento de código
tmux --> Gerenciador de sessões de terminal
rsync --> Sincronizador de repositórios e arquivos

LEIAME.txt: O Manual

O arquivo LEIAME.txt é um arquivo inicial que vem junto do DeByte Server, que serve mais ou menos para auxiliar novatos durante a configuração do servidor, ensinando comandos básicos apenas, deixando isso para o usuário configurar do jeito que quer.

Se caso você não quer ler o manual, fica a vontade para usar "rm LEIAME.txt", afinal, o arquivo é apenas opcional, ele não quebra o sistema.
