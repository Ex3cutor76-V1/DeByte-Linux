Tutorial de 20/07/2026: Como desinstalar o tor?:

O tor é um navegador secundário no DeByte, ele foi pré-instalado para uma função, que seria dar ao user uma oportunidade de navegação anônima, mas, existem pessoas que não querem usar o Tor Browser e está tudo bem, afinal, nem todo mundo quer tanta privacidade assim e aqui está um pequeno tutorial de como "desinstalar" o tor do DeByte: 

Apagar os arquivos do tor: sudo rm -rf /opt/tor-browser/

Só nisso você já desinstala o Tor browser, afinal, ele é só um arquivo no DeByte, mas caso você queira também tirar o alias, use: 

nano ~/.bashrc

E apague essa parte aqui:

tor() {
    if [ -d "/opt/tor-browser" ]; then
        cd /opt/tor-browser && ./start-tor-browser.desktop --detach
        cd ~
    elif ls ~/Downloads/tor-browser*.tar.xz 2>/dev/null | head -1 | grep -q "."; then
        echo "Extraindo Tor Browser..."
        cd ~/Downloads
        tar -xJf tor-browser*.tar.xz
        cd tor-browser
        ./start-tor-browser.desktop --detach
        cd ~
    else
        echo "Tor Browser nao encontrado."
        echo "Baixe em: https://www.torproject.org/download/"
    fi
}

E caso você também queira apagar os serviços você pode usar:

sudo apt purge tor torsocks -y
    sudo apt autoremove --purge

E isso é opcional, já que o Tor Browser é só o navegador e não esses serviços.

Assim você apaga completamente o tor.
